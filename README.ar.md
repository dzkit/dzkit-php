# dzkit لـ PHP 🇩🇿

الأدوات الصغيرة التي يعيد كل تطبيق جزائري كتابتها، مختبرة مرة واحدة ومتاحة للجميع:

- **الحساب البريدي الجاري (CCP / RIP)**: مفاتيح بريد الجزائر، إنشاء الـ RIP والتحقق منه
- **أرقام الهاتف**: التحليل والتحقق والتنسيق ومعرفة المتعامل
- **الرقم الجبائي والرقم الإحصائي (NIF / NIS)**: التحقق من الشكل
- **لوحات ترقيم السيارات**: بما فيها رموز الولايات الجديدة من 59 إلى 69
- **69 ولاية**: الرموز والأسماء بالفرنسية والعربية وتواريخ الإنشاء
- **كتابة المبالغ بالحروف**: بالدينار، بالعربية والفرنسية، للفواتير
- **الأجور**: الضريبة على الدخل الإجمالي (IRG) واشتراكات الضمان الاجتماعي (CNAS)

يعمل على PHP 8.1 فما فوق، بدون أي تبعيات. نفس القواعد ونفس النتائج مثل [dzkit لـ JavaScript](https://github.com/dzkit/dzkit-js): كلاهما يتبع [dzkit-spec](https://github.com/dzkit/dzkit-spec) وينجح في حالات الاختبار المشتركة الـ 339.

**لمعرفة ما يقدمه:** جرّب كل الدوال في [صفحة التجربة على الإنترنت](https://dzkit.github.io/dzkit-js/). تستعمل هذه الصفحة حزمة JavaScript، التي تعطي نفس نتائج هذه الحزمة.

composer require dzkit/dzkit-php

```php
use Dzkit\{Phone, Rip, Words};
use Dzkit\Payroll\Salary;

Rip::fromCcp('23115007');            // '00799999002311500797'
Words::amountAr(1250.5);             // 'ألف ومائتان وخمسون دينارا جزائريا وخمسون سنتيما'
Words::amountAr(2000);               // 'ألفا دينار جزائري'
Words::amountAr(3);                  // 'ثلاثة دنانير جزائرية'
Phone::operator('0771234567');       // 'Djezzy'
Salary::grossToNet(60_000)->net;     // 47558.0
```

## القواعد المطبقة

**الضريبة على الدخل الإجمالي** (المادة 104 من قانون الضرائب المباشرة، جدول قانون المالية 2022، دون تغيير بالنسبة للأجور في 2026):

- إعفاء كامل للدخل الخاضع للضريبة حتى 30 000 دج شهريا
- تخفيض بنسبة 40 % من الضريبة، بين 1 000 و1 500 دج
- من 30 000 إلى 35 000 دج: تخفيض ثان وفق صيغة المديرية العامة للضرائب
- المتقاعدون والعمال ذوو الإعاقة: تخفيض إضافي حتى 42 500 دج
- الحساب كله بأعداد صحيحة، دون أخطاء تقريب

**الضمان الاجتماعي**: 9 % على العامل، و25 % + 0,5 % على صاحب العمل.

**المدخلات والأخطاء والتواريخ** (قواعد مشتركة بين جميع حزم dzkit، انظر [OPERATIONS.md](https://github.com/dzkit/dzkit-spec/blob/main/OPERATIONS.md)):

- دوال التحقق والقراءة لا ترمي أي استثناء: أي قيمة غير صالحة، حتى `null` أو مصفوفة أو رقم بدل نص، تعطي `false` أو `null`
- الأرقام العربية المشرقية (٠١٢…) مقبولة في كل مكان
- الحسابات ترمي `Dzkit\DzkitException` مع `errorCode` (`invalid-amount` أو `invalid-option` أو `no-rule-for-date`) بدل التخمين، مثلا عند نظام غير معروف
- الدوال `Irg::calculate` و`Salary::grossToNet` و`Plate::parse` و`Wilaya::get` تقبل المعامل `$at`: كائن `DateTimeInterface` أو `'YYYY-MM-DD'` (افتراضيا: اليوم بتوقيت الجزائر)

## المصادر

كل قاعدة مبنية على نص رسمي، مرتب حسب تدرج النصوص القانونية الجزائرية. القواعد ومصادرها والأدلة على كل منها محفوظة في [dzkit-spec](https://github.com/dzkit/dzkit-spec)، المشترك بين كل حزم dzkit؛ راجع [تقرير الثقة](https://github.com/dzkit/dzkit-spec/blob/main/TRUST.md).

## ليست استشارة قانونية

هذا مرجع يُحافظ عليه بعناية ومرتبط بمصادره حتى يمكن التحقق من كل قيمة. وهو ليس استشارة قانونية أو جبائية. عندما تكون قيمة ما مهمة، تحقق منها في النص الرسمي، و[افتح issue](https://github.com/dzkit/dzkit-spec/issues) إن وجدت اختلافا.
